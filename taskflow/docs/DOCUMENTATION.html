Project Overview

What is TaskFlow?

TaskFlow is a modern, enterprise-grade full-stack task management system built with Spring Boot 3.2 and React 18. It provides a secure, scalable platform for teams to collaborate on projects, manage tasks, and track progress in real-time.

Key Features

  • JWT-based authentication with role-based access control
  • Full CRUD operations for task management
  • Advanced filtering by status, priority, and ownership
  • Real-time task status updates and lifecycle management
  • User management dashboard with admin controls
  • Comprehensive REST API with Swagger documentation
  • Responsive React frontend with modern UI/UX
  • MongoDB persistence with optimized queries
  • Docker containerization for easy deployment
  • Complete test coverage with JUnit and React Testing Library

Design Principles

Scalability: Built with microservices-ready architecture supporting horizontal scaling.

Security: Enterprise-grade security with JWT, BCrypt, Spring Security 6, and CORS protection.

Performance: Optimized queries, efficient caching, and minimal latency API responses.

Maintainability: Clean code architecture, comprehensive documentation, and extensive testing.

System Architecture

Architecture Overview

TaskFlow follows a classic three-tier architecture with separated concerns and clear boundaries between frontend, backend, and persistence layers.

┌─────────────────────────────────────────────────────────────────┐ │ Frontend Layer │ │ React 18 + Vite + React Router v6 │ │ │ │ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ │ │Dashboard │ │ Tasks │ │ Users │ │ Settings │ │ │ └──────────┘ └──────────┘ └──────────┘ └──────────┘ │ └──────────────────────────┬──────────────────────────────────────┘ │ HTTP/Axios ▼ ┌─────────────────────────────────────────────────────────────────┐ │ API Gateway Layer │ │ JWT Token Validation │ │ Request Routing │ └──────────────────────────┬──────────────────────────────────────┘ │ Spring Security ▼ ┌─────────────────────────────────────────────────────────────────┐ │ Backend Layer │ │ Spring Boot 3.2 + Java 17 │ │ │ │ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ │ │ │Auth Service │ │Task Service │ │User Service │ │ │ └──────────────┘ └──────────────┘ └──────────────┘ │ └──────────────────────────┬──────────────────────────────────────┘ │ Persistence ▼ ┌─────────────────────────────────────────────────────────────────┐ │ Persistence Layer │ │ MongoDB + Spring Data │ │ │ │ ┌──────────────┐ ┌──────────────┐ │ │ │Users Database│ │Tasks Database│ │ │ └──────────────┘ └──────────────┘ │ └─────────────────────────────────────────────────────────────────┘

Data Flow

  1. User initiates action in React frontend
  2. Axios interceptor adds JWT token to request headers
  3. Request sent to Spring Boot API endpoints
  4. Spring Security validates JWT and checks user roles
  5. Service layer processes business logic
  6. Repository layer queries MongoDB
  7. Response JSON returned to frontend
  8. React state updated, UI re-renders

Password Security

Passwords are hashed using BCrypt with configurable strength factor (12 rounds). BCrypt automatically generates a random salt and applies adaptive hashing, making it resistant to brute-force attacks.

State Management with AuthContext

const AuthContext = createContext();

export const AuthProvider = ({ children }) => {
  const [user, setUser] = useState(null);
  const [token, setToken] = useState(localStorage.getItem('token'));
  const [loading, setLoading] = useState(false);

  const login = async (username, password) => {
    const response = await api.post('/auth/login', {username, password});
    const { token, user } = response.data;
    localStorage.setItem('token', token);
    setToken(token);
    setUser(user);
  };

  const logout = () => {
    localStorage.removeItem('token');
    setToken(null);
    setUser(null);
  };

  return (
    <AuthContext.Provider value={{user, token, login, logout}}>
      {children}
    </AuthContext.Provider>
  );
};

Axios Interceptor Pattern

const api = axios.create({baseURL: import.meta.env.VITE_API_URL});

api.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

api.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

Task Lifecycle

Status Flow Diagram

┌─────────────────────────────────────┐ │ Task Creation │ │ (Initial: TODO status) │ └──────────────┬──────────────────────┘ │ ▼ ┌──────────────────────────────────┐ │ TODO │ │ (Not yet started) │ │ Color: #ef4444 (Red) │ └──────────┬───────────────────────┘ │ User clicks "Start Work" │ ▼ ┌──────────────────────────────────┐ │ IN_PROGRESS │ │ (Currently being worked on) │ │ Color: #f59e0b (Amber) │ └──────────┬───────────────────────┘ │ User clicks "Submit for Review" │ ▼ ┌──────────────────────────────────┐ │ IN_REVIEW │ │ (Awaiting approval) │ │ Color: #3b82f6 (Blue) │ └────┬──────────────────────┬───────┘ │ │ Approved │ │ Rejected │ │ ▼ ▼ ┌──────────────┐ ┌──────────────────┐ │ DONE │ │ IN_PROGRESS │ │ Completed │ │ (Back to work) │ │ Color: Green │ └──────────────────┘ └──────────────┘ OR at any time: CANCELLED (Gray)

Status Transitions

  • TODO → IN_PROGRESS: User starts working on task
  • IN_PROGRESS → IN_REVIEW: User submits for review
  • IN_REVIEW → DONE: Manager approves completion
  • IN_REVIEW → IN_PROGRESS: Manager requests changes
  • Any → CANCELLED: Task is cancelled or abandoned

Task Timeline Example

   ↓

   ↓
Submitted: 2024-01-15 15:45:00 UTC (Status: IN_REVIEW)
   ↓
Completed: 2024-01-15 16:00:00 UTC (Status: DONE)

Total Duration: ~6 hours

Troubleshooting

Issue: Backend won't connect to MongoDB
Solution: Check MongoDB is running: mongosh or verify MONGO_URI env variable

Issue: Port 8080 already in use
Solution: Kill process: lsof -ti:8080 | xargs kill -9 or change port in application.yml

Issue: CORS errors from frontend
Solution: Check VITE_API_URL matches backend URL and CORS config in SecurityConfig

Issue: JWT token invalid/expired
Solution: Login again to get fresh token or increase JWT_EXPIRATION value
